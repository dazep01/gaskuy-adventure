**GasKuy Adventure** adalah sistem manajemen perjalanan (trip management) berbasis web yang dirancang khusus sebagai prototipe eksklusif.

## 🛑 PERINGATAN HAK CIPTA
Proyek ini **BUKAN** proyek Open Source. Seluruh kode di dalam repositori ini telah melalui proses enkripsi dan proteksi keamanan tingkat tinggi untuk melindungi aset intelektual pengembang.

### Kebijakan Keamanan:
* **Domain Locked:** Kode hanya akan berfungsi di domain resmi yang terdaftar.
* **Encrypted Logic:** Logika aplikasi disamarkan untuk mencegah duplikasi ilegal.
* **Session Protected:** Akses hanya diberikan kepada klien terpilih melalui gerbang login resmi.

## 📂 Struktur Proyek
Untuk menjaga orisinalitas, hanya file distribusi yang diunggah ke repositori publik ini. File sumber asli (Source Code) disimpan secara privat oleh pengembang.
